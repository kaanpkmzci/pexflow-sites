# LX Resins website

Static site for lxresins.com (EN / DE / TR). No build step.

- `index.html` – page shell
- `assets/content.js` – all texts, products, families and sectors in three languages
- `assets/app.js` – views, routing, language switch, forms
- `assets/site.css` – styles
- `assets/img`, `assets/fonts` – optimised images and self-hosted fonts

Open points: forms are not connected to a mail service; contact details and legal pages are missing; per-language URLs (/en, /de, /tr) are not generated yet.
